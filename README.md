# HUST Computer Systems Experiments

Course experiments for Computer Systems (CSAPP) at Huazhong University of Science and Technology (HUST).

## Contents

- Lab 1 — Data representation and equivalent operations
- Lab 2 — Mixed C/assembly programming and optimization
- Lab 3 — Machine-level program understanding
- Lab 4 — ELF files and program linking

## Notes

Source code and useful text artifacts are retained. Compiled executables, debug bundles, virtual-machine images, QEMU distributions, personal reports, and course materials are intentionally excluded. Lab 5 is therefore not included because its uploaded folder consisted of external tools, a VM image, manuals, and report material rather than publishable source code.
